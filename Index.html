Add / Edit Person

Basic CRUDMVP

CRUD = Create / Read / Update / Delete. Right now this is all client-side, stored in localStorage.

Link Relationships

Parent → child edges

This builds a directed graph: each link is a parent → child edge. The visual tree is rendered by walking the graph from a chosen root.

Backup / Restore

JSON export/import

Export = copy-paste raw JSON into a file / WhatsApp note. Import = paste JSON you previously exported.

Family Tree

Simple DOM-based view

The tree shows descendants of the selected root. "Auto-pick root" chooses someone with no parents (a likely ancestor).

DOM = Document Object Model (browser’s internal tree of HTML nodes). We’re rendering a tree-of-people as a nested <ul>/<li> structure.
