# PaleBlueDot

**Pale Blue Dot** — A simple way to visualize relationships among all beings on our pale blue dot.

This is a local-first, species-agnostic family/connection graph MVP. Data is stored in the browser (`localStorage`) and can be exported/imported as JSON for sharing or backups.

## Quick start
1. Open `index.html` in your browser to run locally.
2. Or push this repo to GitHub and enable GitHub Pages (already set up for this repo).

## How to update live site
1. Edit `index.html` in this repo and commit.
2. GitHub Pages will auto-deploy; the live URL will update shortly.
